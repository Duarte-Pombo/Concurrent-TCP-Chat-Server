# Ideas for review and possible implementation

## Commands

- **Leave room**: this allows the user to go back to the room selection page without having to quit
- **Clear**: maybe the user ants to see the room from a fresh page after topic changes
- **Room settings**: a room can be set to private, add or remove the bot, add or remove users if the room is set to private
- **Ban from room**: creator can block a person from joining even if the room is not private
- **Silence notifications**: do not disturb mode

## Server history

Keep all messages from the rooms for a certain period of time

**TEACHER RECOMMENDATION**: To maintain long term it would require encryption with a key that the user is given when first entering the room

## Private rooms 

When a user creates a room, it can be set to private and users can only join if they are invited by the creator. There would be a section in the starting page with private rooms and pending invitations

## Direct messages

Users can see who is currently online and direct message them

## Notifications

Show to the destined user if they are not in the chat that originated it

## Main page

- Create room
- Public rooms
- Private rooms joined
- Private rooms invites
- DMs active
- Notifications
